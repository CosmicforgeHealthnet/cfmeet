# CF Meet Part V v2.0 — backend requirement matrix at backend closure

Companion to `docs/phases/phase-05/part-v-backend-only-closure.md` (section 2). Every row of the
baseline audit (taken at `71013c7` before any change on branch `part-v-backend-closure`) is kept;
rows that were PARTIAL / ABSENT / IMPLEMENTED-UNTESTED carry a **Closure** note naming the gap, the
commit that closed it and the test that proves it. Specification: CF Meet Part V v2.0
(Parts A–L, §§1–166, Appendices G–N).

Status legend: **IT** implemented and tested · **NB** non-backend / external, carried forward (never
counted as PASS) · **IT / NB** backend part implemented and tested, external part carried forward ·
**NR** not a requirement (informational / process). Test references are `file::test_fn` under
`services/messaging/tests/` unless a path is given; abbreviations: `msg/` services/messaging,
`crypto/` packages/messaging-crypto, `ms/` services/meeting-service, `pr/` services/privacy-relay,
`sg/` services/sms-gateway, `pa/` services/platform-access.
