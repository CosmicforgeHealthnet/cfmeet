# Delivery phases

Each CF Meet delivery phase has its own folder for its specification,
decisions and acceptance/validation reports:

```
docs/phases/
├── phase-01/
├── phase-02/   ← Meeting & Conference Platform (next)
├── ...
└── phase-10/
```

Create a phase folder when its specification is added. Folders are not
pre-created empty, and no phase documents are fabricated. The Phase 2
specification is **not yet in the repository**; add it at
`docs/phases/phase-02/` (for example `docs/phases/phase-02/SPEC.md`) before
implementation starts.

The repository consolidation and layout restructure that preceded Phase 2 is
recorded in [`../migration/MONOREPO_MIGRATION.md`](../migration/MONOREPO_MIGRATION.md).
