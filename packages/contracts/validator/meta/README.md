of the official schemas published by the OpenAPI Initiative
(<https://spec.openapis.org/oas/>, source repository `OAI/spec.openapis.org`), licensed
under the Apache License 2.0:

| File | Upstream id |
|---|---|
| `oas-3.0-2021-09-28.schema.json` | `https://spec.openapis.org/oas/3.0/schema/2021-09-28` |
| `oas-3.1-2022-10-07.schema.json` | `https://spec.openapis.org/oas/3.1/schema/2022-10-07` |

Update by replacing a file with a newer published version and adding it to the validator.
