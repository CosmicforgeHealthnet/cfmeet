# Changelog

## 0.1.0 (unreleased, beta)

- Generated client for the public CF Meet platform API (499 operations), realtime,
  webhook verification, pagination, idempotency and the Messaging E2EE bridge.
- Generated typed models per public domain (`package:cfmeet_platform_sdk/models/<domain>.dart`):
  read-only views with typed getters, `create(...)` builders and lossless `toJson()`.
